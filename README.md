# Mario Builder 64
Mario Builder 64 is a Super Mario 64 ROM hack that allows you to create custom levels in-game. Mario Builder 64 was built on top of the source code of **SM64: Beyond the Cursed Mirror** and uses the **HackerSM64** repo as a base. Level editor-specific code can be found in `src/mb64/` (editor, gfx, and menu modules). Some code is unsightly and abominable, so exercise caution to those who view it.

When building from a freshly cloned repo, the baserom extractor will overwrite a lot of assets. To fix this, simply discard all the extra changes that appear in your source control tab.

For a compilation guide, see the [HackerSM64 README](https://github.com/HackerN64/HackerSM64).
